# 🚢 Titanic AI Analytics & Survival Predictor

An End-to-End interactive Data Analytics and Machine Learning web application built using Python, Streamlit, Plotly, and Scikit-Learn.

## 🚀 Live Demo
Check out the live interactive app deployed on Streamlit Cloud: **[Add Your Live Link Here]**

## 📌 Features
- **Key Performance Indicators (KPIs):** Real-time summary metrics (Total Passengers, Survival Rate, Avg Fare).
- **Interactive Visualizations:** Filterable multi-variable distribution and correlation charts powered by Plotly.
- **AI Prediction Engine:** Real-time passenger survival prediction powered by a Scikit-Learn `RandomForestClassifier`.
- **SQL Data Pipeline:** SQLite database integration for direct analytical querying.

## 🛠️ Tech Stack
- **Languages:** Python, SQL
- **Libraries:** Pandas, NumPy, Scikit-Learn, Plotly, Streamlit, SQLite3
- **Tools:** Git, GitHub, Linux (Kali)
